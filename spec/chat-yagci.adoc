== Fragen zur Anforderungsanalyse (Yagci)

=== 1. UI/UX: Editieren und Löschen
* *Positionierung:* Wo sollen der Editier- und Lösch-Button auf der Karteikarte platziert werden?
* Antwort: Bevorzugt in der rechten oberen oder unteren Ecke der Karteikarte als kleine Icons (Stift für Editieren, Mülleimer für Löschen).
* *Dialoge:* Soll beim Klick auf "Editieren" ein Modaler Dialog ähnlich dem "Erstellen"-Dialog geöffnet werden?
* Antwort: Ja, ein modaler Dialog ist am besten, damit der Ablauf konsistent zum Erstellen bleibt.
* *Lösch-Bestätigung:* Wie soll die Bestätigung beim Löschen aussehen? Reicht ein einfacher "Bist du sicher?"-Alert?
* Antwort: Ja, ein Standard-Bestätigungs-Dialog (Confirmation Alert) von JavaFX reicht völlig aus.

=== 2. Datenhaltung & Logik
* *Persistenz:* Die Änderungen müssen persistent sein. Wird dazu beim Aktualisieren und Löschen jeweils die existierende `updateDeck()`-Methode bzw. `save()`-Methode der `Model`-Klasse wiederverwendet?
* Antwort: Ja, die aktuelle JSON-Dateispeicherung in `decks.json` über das Model soll direkt nach jedem Vorgang aktualisiert werden.
