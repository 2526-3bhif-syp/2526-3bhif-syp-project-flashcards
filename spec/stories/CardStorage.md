# Story

As a student I want to create a flashcard with a question and an answer so that I can learn digitally.

# Acceptance Criteria

* There is a button to create a new flashcard
* A flashcard must contain a question field and an answer field
* Both fields are mandatory before saving
* After saving, the card appears in the overview
* The card data is stored persistetly

# Priority

- High

# Effort
