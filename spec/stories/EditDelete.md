# Story

As a student I want to edit and delete my flashcards so that I can correct or remove outdated content.

# Acceptance Criteria

* Each flashcard has an edit button
* Each flashcard has a delete button
* Editing allows changing question and answer
* Changes are saved persistently
* Deleting a card removes it permanently after confirmation
* After deletion, the card no longer appears in the overview

# Priority

- High
