## Story

- As a student I want to add audio files to my cards in order to learn pronunciation.

## Acceptance Criteria

- There should be an upload button for the audio file at every card.
- There should be a delete button for the audio file.
- The audio file should be saved at the card.
- There should be a button to listen to the audio file on the card.
- The name and the lenght (minutes, seconds, ...) of the audio file should be diplayed.

## Priority

- Low

## Effort

- 5
