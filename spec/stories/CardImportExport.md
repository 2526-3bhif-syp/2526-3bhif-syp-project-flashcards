# Story
- As a student I want to import and export flashcards in order to share them
# Acceptance Criteria
- export is a common file like json, so that other programs are able to read it without problems
- import should read the same file format without problems
- while exporting and importing, no data should get lost
- when importing the user should have the choice to allow duplicates or not
- There should be one button for import and one for export. After clicking you can choose the format
# Priority
- High
# Effort
- 5
